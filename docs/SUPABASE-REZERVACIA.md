Výsledková stránka posiela rezerváciu hovoru (telefónne číslo) na tú istú funkciu
ako lead z kvízu. Rozlišuje ich pole **`typ: 'konzultacia'`**.

---

## 1. Čo stránka posiela

`POST` na `…/functions/v1/quizLead`, `Content-Type: application/json`:

```json
{
  "typ": "konzultacia",
  "name": "Zuzana",
  "email": "zuzana@example.com",
  "phone": "+421 900 123 456",
  "preferredTime": "Zajtra doobeda",
  "segment": "vecerne-chute",
  "history": "viackrat",
  "readiness": "podpora",
  "band": "expertka",
  "tier": "hot",
  "score": 7,
  "ts": "2026-07-30T05:15:34.035Z",
  "source": "pravda-o-chudnuti-hovor",
  "quizVersion": 3
}
```

`preferredTime` je jedna zo štyroch možností alebo prázdny string:
*Dnes večer · Zajtra doobeda · Zajtra večer · Kedykoľvek mi to zavolaj*

## 2. Čo musí funkcia vrátiť

**Toto je záväzné.** Klient neverí len stavu `200` — vyžaduje potvrdenie, že sa
telefón naozaj uložil:

```json
{ "ok": true, "kind": "call" }
```

Bez `kind: "call"` (alebo `typ: "konzultacia"`) klient zápis vyhodnotí ako **neúspešný**,
zobrazí záložné cesty (Cal.com, e-mail) a **nepošle konverziu `Lead`**.

Dôvod: funkcia, ktorá o `typ: 'konzultacia'` nevie, request prijme a neznáme polia
tichu zahodí. Dostali by sme `200`, odpálili konverziu a človeku napísali „ozvem sa ti
na 0900…" — pričom číslo by nikde nebolo. To je horšie než keby sa formulár vôbec
nezobrazil.

## 3. Tabuľka

```sql
create table if not exists quiz_calls (
  id          bigint generated by default as identity primary key,
  created_at  timestamptz not null default now(),
  name        text,
  email       text,
  phone       text not null,
  preferred_time text,
  score       int,
  segment     text,
  history     text,
  readiness   text,
  band        text,
  tier        text,
  source      text,
  quiz_version int,
  called      boolean not null default false   -- odškrtávaš si, komu si už volal
);

alter table quiz_calls enable row level security;
-- Bez policy na SELECT/anon: zapisuje service role vnútri funkcie,
-- čítaš to cez dashboard. Číslo sa tak nedá vytiahnuť z prehliadača.
```

## 4. Kód do `quizLead`

Vlož **na začiatok** handlera, hneď za spracovanie CORS a parsovanie tela — teda
**pred** existujúcu logiku leadu, aby rezervácia nespadla do vetvy pre kvíz:

```ts
const body = await req.json();

// ---- REZERVÁCIA HOVORU Z VÝSLEDKU KVÍZU ----
if (body.typ === "konzultacia") {
  const phone = String(body.phone ?? "").trim();
  // Bez čísla nemá rezervácia zmysel — nech to klient zobrazí ako chybu.
  if (phone.replace(/\D/g, "").length < 9) {
    return new Response(JSON.stringify({ ok: false, error: "phone" }), {
      status: 400,
      headers: { ...corsHeaders, "Content-Type": "application/json" },
    });
  }

  const { error } = await supabase.from("quiz_calls").insert({
    name: body.name ?? null,
    email: body.email ?? null,
    phone,
    preferred_time: body.preferredTime ?? null,
    score: body.score ?? null,
    segment: body.segment ?? null,
    history: body.history ?? null,
    readiness: body.readiness ?? null,
    band: body.band ?? null,
    tier: body.tier ?? null,
    source: body.source ?? null,
    quiz_version: body.quizVersion ?? null,
  });

  if (error) {
    return new Response(JSON.stringify({ ok: false, error: error.message }), {
      status: 500,
      headers: { ...corsHeaders, "Content-Type": "application/json" },
    });
  }

  // Notifikácia — aby si sa o čísle dozvedel do minúty, nie keď otvoríš dashboard.
  // Človeku bolo sľúbené „ozvem sa ti", takže toto nie je nice-to-have.
  try {
    await fetch("https://api.resend.com/emails", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${Deno.env.get("RESEND_API_KEY")}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        from: "Kvíz <noreply@valyra.sk>",       // musí byť overená doména v Resende
        to: "karas.jan2@gmail.com",
        subject: `📞 Rezervácia hovoru: ${body.name ?? "?"} (${phone})`,
        text:
          `Telefón: ${phone}\n` +
          `Kedy volať: ${body.preferredTime || "neuviedla — zavolaj čo najskôr"}\n` +
          `Meno: ${body.name ?? ""}\n` +
          `E-mail: ${body.email ?? ""}\n\n` +
          `--- Čo o nej vieš z kvízu ---\n` +
          `Skóre: ${body.score ?? "?"}/8\n` +
          `Hlavná brzda: ${body.segment ?? "?"}\n` +
          `História: ${body.history ?? "?"}\n` +
          `Chce: ${body.readiness ?? "?"}\n` +
          `Tier: ${body.tier ?? "?"}\n`,
      }),
    });
  } catch (_) {
    // Mail je len notifikácia. Ak zlyhá, rezervácia je už v tabuľke —
    // preto sa tu úspech NERUŠÍ.
  }

  // Potvrdenie, ktoré klient vyžaduje. Bez `kind` to klient vyhodnotí ako zlyhanie.
  return new Response(JSON.stringify({ ok: true, kind: "call" }), {
    status: 200,
    headers: { ...corsHeaders, "Content-Type": "application/json" },
  });
}
// ---- KONIEC REZERVÁCIE, ďalej pokračuje pôvodná logika leadu ----
```

**Pozn.:** názvy `supabase` (klient) a `corsHeaders` použi tie, ktoré už v tvojej
funkcii sú. Ak sa telo požiadavky parsuje inde, `body` neduplikuj.

## 6. Záložná cesta: Apps Script

V `apps-script.gs` je pripravená vetva `typ === 'konzultacia'` →
`handleHovorZKvizu_()`, ktorá zapíše do listu **„Hovory z kvízu"** a pošle e-mail.
Ak by Supabase cesta robila problémy, stačí `CONFIG.BOOKING_URL` prepnúť na URL
Apps Script web appky (`…/exec`) — **a zmeniť `Content-Type` na
`text/plain;charset=utf-8`**, pretože Apps Script neobsluhuje preflight `OPTIONS`.
